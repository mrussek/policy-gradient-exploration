How Policy Gradient Works

REINFORCE is a policy gradient algorithm. A neural network (the policy) outputs action probabilities given the game state. After each episode:

  1. Collect trajectory: states, actions, rewards
  2. Compute returns Gt with discount γ
  3. Update weights: ∇θ J ≈ ∑ ∇ log π(a|s) · Gt

Good actions get reinforced; bad actions get suppressed.
